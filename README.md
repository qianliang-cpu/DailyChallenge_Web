# DailyChallenge_WebFrontend

web部2026纳新每日一题（前两周：HTML / CSS / JavaScript）

请克隆仓库以获取每日一题

## 学习方式

每天一个文件夹（Day_0 ~ Day_13），**先看教程再动手做**，每天控制在 **30 分钟以内**：

1. 打开当天文件夹的 `README.md`
2. 先点开"先学（教程）"里的链接学习（文字教程为主，B站视频选看、卡住再点开）
3. 再做"任务"，卡住才看"参考解答"
4. 把运行结果（截图或代码）贴在**当日工单**的评论里

## 提交方式

请在该工单下方"撰写"处提交你的文件然后点击"评论"，如果显示"登录 并参与到对话中"就请点击"登录"并注册你的账户

## 课程安排（前两周）

| --- | --- | --- |

## 环境准备（Day_0 会详细讲）

- 编辑器：VS Code（https://code.visualstudio.com/）
- 浏览器：Chrome / Edge（自带的 F12 开发者工具是前端调试利器）
- 运行环境：Node.js（https://nodejs.org/ ，第二周 JS 需要用 `node` 命令运行脚本）
