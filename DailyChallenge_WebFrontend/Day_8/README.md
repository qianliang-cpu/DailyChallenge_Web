# Day_8 · 数据类型转换与运算符

> 预计耗时：20~30 分钟
> 用户输入到网页里的都是字符串，要做计算得先"转换类型"。今天学转换和算术运算。

## 今日知识点

- 字符串 → 数字：`Number("18")`；数字 → 字符串：`String(18)`
- 算术：`+` `-` `*` `/` `%`（取余）
- 注意：`+` 用在字符串上是**拼接**，不是相加

## 参考解答（先做再看）

```javascript
"1" + "2"        // "12"  —— 字符串拼接
1 + 2            // 3     —— 数字相加
Number("18") + 1 // 19    —— 转成数字再相加
"18" + 1         // "181" —— 数字被转成字符串拼接
10 % 3           // 1     —— 10 除以 3 余 1
```
